## Ejercicio Building

1. Crear un workflow llamado "Build App"
2. El workflow debe ejecutarse manualmente y a través de un push a la rama main
3. Se debe recibir un parámetro de entrada llamado environment como input, colocar por defecto el environment dev
4. El workflow debe compilar una aplicación de cualquier tecnología (java, .net, js, python, etc)
5. Debes subir el artefacto al workflow.
6. Implementar una tarea que imprima el nombre del environment (considerar que sólo debe imprimirse cuando el environment es dev)
